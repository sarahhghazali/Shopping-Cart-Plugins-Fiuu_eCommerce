Introduction
-----

This is the Fiuu MOLPay Normal integration plugin for WP eCommerce. It enables secure payment processing for WP eCommerce-based online stores via Fiuu's payment gateway.

Notes / Prerequisite
-----

Fiuu is not responsible for any problems that might arise from the use of this module.
Use at your own risk. Please backup any critical data before proceeding. For any query or
assistance, please email support@fiuu.com.
